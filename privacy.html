Privacy Policy

Last updated: November 16, 2026

What this app is

"bitexplainsdaily" is a private tool used only by the owner of the YouTube channel Bit Explains. It uploads videos that the channel owner created to the channel owner's own YouTube channel. It is not offered to other users.

What data the app uses

The app uses Google OAuth with the single permission to upload videos (youtube.upload). It only accesses the account of the channel owner who signed in. It does not read, collect, store or share personal data of anyone else.

How access data is stored

The access token is stored as an encrypted secret in the channel owner's private GitHub repository and is used only to upload new videos.

Use of Google user data

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. No data is sold, shared with third parties or used for advertising.

Data retention and deletion

The tool stores no personal data. The only stored credential is the owner's own access token, which is deleted by removing it from the GitHub repository secrets or by revoking access.

YouTube Terms and Google Privacy Policy

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the YouTube channel Bit Explains.
